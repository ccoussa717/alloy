# Support

## Questions and usage help

Search [GitHub Issues](https://github.com/ccoussa717/alloy/issues) before opening
a new question or usage request.

Alloy is provided without a support warranty under the MIT License. Maintainers
prioritize security issues, regressions in supported releases, and reproducible
bugs.

## Bugs

Before filing a bug, run:

```bash
alloy --version
# Then start Alloy and run /doctor inside the session.
```

Never paste `auth.json`, API keys, bearer tokens, private prompts, or customer
data into an issue.

## Security

Do not report vulnerabilities through public channels. Follow
[SECURITY.md](./SECURITY.md) and use GitHub's private vulnerability-reporting
form.
